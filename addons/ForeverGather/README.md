# ForeverGather

**Version 2.2.0 — WoW Classic Era**  
Author: **0xgle**

ForeverGather is a local-first gathering intelligence addon for Mining, Herbalism and Skinning.

It learns successful gathering locations while you play, displays compact markers on the Minimap and World Map, and builds Smart Routes through learned locations.

## Features

- Mining, Herbalism and Skinning location learning
- Successful-loot validation to reduce false node records
- Hollow learned-node markers so Blizzard live tracking dots remain visible
- Smart Route generation and optimization
- Route lines on the Minimap and World Map
- Off-screen NEXT guidance
- Session analytics and confidence tracking
- GatherMate2 import
- TomTom integration
- Zone export, Diagnostics and Data Doctor
- Local-first storage
- No protected-action automation

## Commands

```text
/fg
/fg bar
/fg route
/fg route clear
/fg route next
/fg focus <name>
/fg focus clear
/fg reset
/fg import gathermate
/fg diag
/fg export
/fg prune
```

## Installation

Copy the `ForeverGather` folder to:

```text
World of Warcraft/_classic_era_/Interface/AddOns/
```

Then reload the UI and type `/fg`.
