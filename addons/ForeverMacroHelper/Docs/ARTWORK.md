# Artwork

Two new raster assets were generated with the built-in image generation tool for this release and are actually consumed by the Lua UI. Existing Forever icons are retained from the user's supplied suite.

- `Media/Textures/grimoire.tga`: new full window background, uncompressed 1024 x 1024 RGB TGA; mapped onto the 1120 x 744 window.
- `Media/Icons/macro.tga`: new book/quill launcher, uncompressed 128 x 128 RGBA TGA; used in the title, macro pickup control and optional minimap launcher.
- Shared control icons: search, settings, favorite and close.
- Class icons come from the game's own class atlas and remain crisp, recognisable class marks.

The artwork contains no baked text. Labels, requirements, buttons and macro bodies are native live UI elements.
