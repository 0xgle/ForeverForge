# Changelog

## 0.2.0-beta1

- Rebuilt the working 0.1.1 prototype UI with the Forever family palette and sixteen generated, in-use icons.
- Separated core, features, UI and settings modules.
- Added a full settings window, copy dialog, editable word filters and Saved view.
- Reflowed chat when the sidebar is hidden; bounded resizing prevents sidebar control collisions.
- Preserved reading position by pausing renders when scrolled up; batched incoming renders.
- Added LFG role/dungeon filtering, expiry, LF2M recognition and distinct full-name Dire Maul handling.
- Added character-separated history, optional session-only capture and bounded persistent bookmarks.
- Fixed missing optional event arguments during dispatch by preserving vararg count.
- Added notification controls, combat quiet mode, optional class colors and native reply drafts.
- Limited duplicate cache lifetime, network greeting frequency and danger reports.
- Added optional minimap button (off by default), binding and persistent position anchors.
- Retained visible by 0xgle attribution and rights notice.
