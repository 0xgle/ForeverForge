# Artwork — ForeverChat Sanctum

Created with the built-in image-generation tool. Converted to uncompressed,
24-bit, power-of-two TGA textures for the addon. These are actual runtime assets.
No external download or ForeverCore installation is needed for textures.

## Runtime files

- Media/Sanctum.tga — generated header art, 1024×256, cropped in the UI.
- Media/Obsidian.tga — stone area from the header artwork, 512×256.
- Media/Chat.tga, Group.tga, Guild.tga, Whispers.tga — generated icons, 128×128.
- Media/Radar.tga, Trade.tga, Alerts.tga, Settings.tga — generated icons, 128×128.

Original addon code: by 0xgle. Text and controls are rendered separately in WoW.

## Header generation prompt

Use case: stylized-concept. Production game UI asset, a single horizontal header texture for ForeverChat, an MMORPG chat addon in the Forever collection. 1536x1024 image. Composition: ancient obsidian communication chamber with engraved aged brass architecture, subtle teal energy veins. An exquisite small arcane messenger crystal inside a brass circular instrument at the FAR RIGHT, occupying only the rightmost quarter. The left 70 percent is almost black finely textured stone, calm empty negative space for separately rendered gold UI title. Restrained gold edge engravings along the very top and bottom. Straight-on flat panoramic art, no perspective UI mockup, no lettering, no words, no logo, no buttons, no characters. Sophisticated World of Warcraft fantasy inventory interface craftsmanship, antique brass rather than bright yellow, turquoise glow rather than blue, very dark and readable. Art will be cropped to its middle horizontal band for a 1000x90 header; keep instrument centered vertically and all interesting details inside the middle 40 percent height. Save generated image to local file for incorporation into an addon.

## Icon atlas generation prompt

Use case: stylized-concept. Production game UI sprite atlas, exactly 4 columns by 2 rows, 8 equal square cells, 1536x1024 canvas. Each icon centered in its own cell with generous 22 percent inner padding, no grid lines, uniform near-black obsidian background. Painterly high detail antique brass and subtle luminous turquoise fantasy MMORPG icons matching an ancient arcane communication console. Row 1 left to right: ornate speech bubble with teal gemstone (chat), two medieval adventurer silhouettes in brass medallion (group), heraldic shield with teal inset (guild), sealed parchment envelope with turquoise seal (whispers). Row 2 left to right: antique compass with teal needle (LFG radar), balance scales with coins (trade), warning triangle with teal crystal and warm gold edge (alerts), cogwheel with teal center (settings). All eight fully visible isolated icons, consistent size and lighting, no letters, no text, no numbers, no UI mockup. Designed to be cropped into separate game icon textures.
